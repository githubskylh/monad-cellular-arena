## 🎯 2. 核心系统机制与创新突破

### 🏛️ 一、三界三宗随时转职体系 (Dynamic Sect Switching)
* 🗡️ **人族 • 大唐官府（剑侠客）**：物理极端爆发！【普攻斩击】+【横扫千军】（三连刺破防递增暴击）+【破釜沉舟】（全屏环形太极风暴剑气）。
* 🐉 **仙族 • 龙宫（龙太子）**：法术狂涛倾覆！【水波冲击】+【龙腾九天】（狂澜水龙单体轰鸣）+【龙卷雨击】（呼风唤雨全场雷鸣轰击）。
* 🦁 **魔族 • 狮驼岭（虎头怪）**：狂暴多怪扑杀！【重锤破击】+【狂暴变身】（魔兽之躯倍增战力）+【鹰击长空】（大鹏化影疾风扑杀）。

### 🛒 二、藏宝阁全链去中心化 C2C 寄售行 (On-Chain Bazaar)
* **神兵挂牌出售**：持有神兵的玩家输入期望售价（以原生 MON 计价），单笔交易上架至全链集市。
* **点对点买断交割**：其他少侠在集市一键支付原生 MON，合约原子化完成款项给付与 NFT 拥有权过户。
* **防作弊安全护栏**：穿戴在纸娃娃槽位中的装备不可挂单，必须先卸下方可寄售，杜绝虚假交易。

### ⚔️ 三、长安城擂台比武与战神榜 (Chang'an Arena Duels)
* 玩家可凭全身神兵总战力挑战擂台守擂弟子（或各派名宿）。
* 战力优胜者将战绩永久写入 Monad 区块高度，累加战神胜场与修为积分！

### 🎮 四、三大多样化关卡与 Boss 战 (Multi-Stage Progression)
* **第一章 • 东海沉船**：水波粼粼，击破东海大海龟、珊瑚巨蛙与海盗。
* **第二章 • 江南野外**：落英缤纷，伏魔嗜血野猪、幽冥骷髅、千年树精与刺客。
* **第三章 • 大雁塔决战**：梵音阵阵，斩破羊头怪、夺命花妖，决战巨型 **【大雁塔镇塔妖王】**！
